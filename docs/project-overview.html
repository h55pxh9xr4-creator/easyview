Startup 자동 마이그레이션

  1. Base.metadata.create_all() — 신규 테이블 생성
  2. FAQ 초기 7건 seed (count == 0 일 때만)
  3. 고객사 FAQ 24건 JSON upsert (idempotent)
  4. 빌링 xlsm 있으면 import (Asset/ 폴더)
  5. 빌링 master 비어있으면 샘플 시드 (8법인)
  6. inquiry.reply → inquiry_reply 테이블 이관 (idempotent)
  7. corporation 컬럼 없으면 ALTER TABLE
  8. je_data · tb_data → je · tb_account view 교체
